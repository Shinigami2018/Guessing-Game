# 🎯 Guessing Game

Welcome to the classic number guessing game — with a fresh look!  
Can you guess the secret number before your chances run out?

## 🕹️ How to Play

1. Open `index.html` in your browser.
2. Guess a number between 1 and 100.
3. The game tells you if you're too high, too low, or spot on.
4. Try to win in as few tries as possible!

## ✨ Features

- Simple, colorful UI
- Instant feedback
- Unlimited fun
